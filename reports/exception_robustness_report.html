1. Executive Summary & Audit Scope

This audit evaluates the exception handling architecture, runtime robustness, and argument safety across the ANTsPyMM package. Using a combination of AST walking, static linters (ruff rules E722, B006, B008, B904, B028), and live mutation tests, we established:

  • Zero Bare Excepts: All 12 previously unconstrained except: clauses were successfully modernized to except Exception:.

  • Unidiomatic Dictionary Access: In blind_image_assessment, metadata extraction relies on 6 redundant try ... except Exception: pass blocks instead of dictionary .get().

2. Mutable Default Arguments & In-Place Mutation (B006)

CRITICAL HAZARD CONFIRMED EMPIRICALLY: generate_mm_dataframe mutates shared default lists in memory and permanently corrupts caller lists.

The Bug: In-Place Mutation

In antspymm/mm.py lines 714–722:

def generate_mm_dataframe(
    ...,
    rsf_filenames=[],
    dti_filenames=[],
    nm_filenames=[]):

    if len(rsf_filenames) < 2:
        for k in range(len(rsf_filenames), 2):
            rsf_filenames.append(None) # MUTATES SHARED OBJECT!

Because default arguments are evaluated once at module load, rsf_filenames becomes [None, None] for all subsequent calls.

The Fix: Safe Initialization

Idiomatic immutable default pattern:

def generate_mm_dataframe(
    ...,
    rsf_filenames=None,
    dti_filenames=None,
    nm_filenames=None):

    # Create fresh local copies
    rsf_filenames = list(rsf_filenames) if rsf_filenames else []
    dti_filenames = list(dti_filenames) if dti_filenames else []
    nm_filenames = list(nm_filenames) if nm_filenames else []

Guarantees isolation between function calls and prevents mutating caller arguments.
